## Decided
- PKGS array in src/claude/shim-template.ts (L67) must list '@detacoop/trail-code' as first entry, before '@trailhq/trail-code' and '@nanonets/graft'.
- Without this, hook.cjs generated by trail init never finds the fork when a teammate installs it by package name. This machine works via install.json → remembered() but others won't.
- After changing shim-template.ts: npm run build → npm install -g . --ignore-scripts → trail init --no-build --yes for each wired repo (re-generates hook.cjs).
